# Orkeit Desktop — تطبيق مستقل للهاتف

هذا مجلد تطبيق **Orkeit Desktop** المستقل، منفصل وظيفيًا عن تطبيق زيارات الدفاع المدني. لا يستورد كود التطبيق الأساسي ولا يستخدم Firebase أو بياناته.

## نشره كتطبيق مستقل على Vercel

أنشئ مشروع Vercel جديدًا (لا تغيّر إعدادات مشروع الزيارات الحالي) ثم اربطه بالمستودع:

- Repository: `mohmedelmotaz151-ctrl/Orekit-STM`
- Branch: `feature/windows-mobile-desktop`
- **Root Directory:** `windows-mobile-desktop`
- Framework Preset: `Other`
- Build Command: اتركه فارغًا
- Output Directory: اتركه فارغًا أو استخدم `.` إذا طلبت الواجهة ذلك
- Install Command: اتركه فارغًا

سيكون له عنوان نشر مستقل خاص به. لا تدمج هذا الفرع في `main` ولا تغيّر مشروع Vercel الخاص بالزيارات من أجل نشره.

## الوظائف الحالية
- واجهة سطح مكتب عربية RTL وشريط مهام وقائمة ابدأ.
- فتح الروابط في متصفح النظام.
- رسام يعمل باللمس ويحفظ اللوحة بصيغة PNG.
- اختيار ملفات من الهاتف عبر منتقي الملفات الذي يوفره النظام.
- معاينة PDF عبر عارض المتصفح إذا كان مدعومًا، ومعاينة الصور والنصوص.
- Service Worker لتخزين الملفات الأساسية للعمل دون اتصال بعد أول زيارة.

## تثبيته على هاتف TECNO KJ6
بعد نشره عبر HTTPS، افتح رابط Orkeit Desktop في Chrome على الهاتف، ثم قائمة المتصفح واختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** إذا ظهر الخيار. سيظهر كتطبيق مستقل عن تطبيق الزيارات.

## حدود مهمة
هذا المشروع **واجهة ويب تقدمية (PWA)، وليس نظام Windows حقيقيًا ولا محاكي Windows**. لا يشغّل ملفات `.exe`، ولا يضم Google Chrome الأصلي أو إضافات Chrome المكتبية. المتصفح يفتح المواقع في المتصفح الخارجي، ولا يمكن للتطبيق تصفح كل ملفات الهاتف إلا عبر اختيار المستخدم للملفات.

لتشغيل برامج Windows الأصلية يلزم تطبيق Android أصلي مع محرك توافق مناسب أو اتصال بكمبيوتر Windows؛ لا يمكن تحقيق ذلك بواجهة PWA وحدها.

## الاستقلال عن تطبيق الزيارات
- ملفات هذا التطبيق محصورة داخل `windows-mobile-desktop/`.
- لا تغيّر ملفات التطبيق الأساسي أو إعدادات Firebase.
- استخدم مشروع Vercel جديدًا ونطاقًا منفصلًا لهذا التطبيق.
- هذه الإعدادات لا تعني أن التطبيق نُشر بالفعل؛ يلزم إكمال ربط مشروع Vercel الجديد.
