# Orkeit Desktop (Mobile PWA)

واجهة ويب تقدم سطح مكتب مستوحى من Windows للهاتف، ويمكن تثبيتها كتطبيق ويب تقدمي (PWA) عند استضافتها عبر HTTPS.

## الوظائف الحالية
- واجهة سطح مكتب عربية RTL وشريط مهام وقائمة ابدأ.
- فتح الروابط في متصفح النظام.
- رسام يعمل باللمس ويحفظ اللوحة بصيغة PNG.
- اختيار ملفات من الهاتف عبر منتقي الملفات الذي يوفره النظام.
- معاينة PDF عبر عارض المتصفح إذا كان مدعومًا، ومعاينة الصور والنصوص.
- Service Worker لتخزين الملفات الأساسية للعمل دون اتصال بعد أول زيارة.

## التشغيل
افتح `index.html` عبر خادم محلي أو استضف مجلد `windows-mobile-desktop` على خدمة تدعم الملفات الثابتة وHTTPS. من Chrome على أندرويد، افتح الموقع ثم قائمة المتصفح واختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** إذا ظهر الخيار.

## حدود مهمة
هذا المشروع **ليس نظام Windows ولا محاكي Windows**. لا يشغّل ملفات `.exe`، ولا يضم Google Chrome الأصلي أو إضافات Chrome المكتبية. المتصفح يفتح المواقع في المتصفح الخارجي، لأن تضمين مواقع كثيرة داخل iframe تمنعه سياسات المواقع. لا يمكن لـ PWA تصفح كامل ملفات الهاتف دون أن يختارها المستخدم صراحةً.

لإضافة تشغيل برامج Windows الأصلية يلزم مشروع Android أصلي يدمج/يستدعي محرك توافق مناسب أو ميزة اتصال بكمبيوتر Windows. هذا خارج نطاق واجهة PWA وحدها.

## المسار
`windows-mobile-desktop/` داخل مستودع Orekit-STM، كجزء مستقل لا يغيّر ملفات التطبيق الأساسي.
